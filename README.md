# gubby 🐰
le epic github "package manager"

## usage
gubby.exe [COMMAND]

## commands
- check         checks packages for updates
- config        opens gubby config file
- install       installs a package
- list          lists all installed packages
- self-install  installs the gubby binary
- self-upgrade  installs the latest version of gubby
- uninstall     uninstalls a package
- update        updates all installed packages
